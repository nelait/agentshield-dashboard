Data Model#

Two layers: the TypeScript domain model in gateway/src/types.ts, and the SQLite schema in gateway/src/db.ts. The domain model is the one to learn — the schema is largely a serialisation of it.

The domain model#

ControlObjective — the centre of the system#

Everything compiles from this. Extraction produces it; review approves it; both Rego streams and both evaluation engines read it.

interface ControlObjective {
  id: string;                 // "ctl-gdpr-art32"
  framework: Framework;       // GDPR | CCPA | SOC2 | ISO27001 | NIST_CSF | HIPAA | PCI_DSS
  article: string;            // "GDPR Art. 32" — the human citation
  title: string;
  description: string;
  category: ControlCategory;  // encryption | network | access-control |
                              // data-protection | ai-governance | logging
  severity: Severity;         // low | medium | high | critical
  status: ControlStatus;      // extracted | approved | rejected
  confidence: number;         // 0..1, from extraction
  sourceDocId?: string;
  static: StaticTarget[];     // → grc.static
  runtime: RuntimeTarget[];   // → grc.runtime
  reviewedBy?: string;
  reviewedAt?: string;
}

The dual-governance model lives in those two arrays: one reviewed control, two enforcement surfaces.

StaticTarget — an IaC rule#

interface StaticTarget {
  provider: "terraform" | "kubernetes" | "cloudformation";
  resourceTypes: string[];   // ["aws_s3_bucket"] or ["Pod"] or ["AWS::S3::Bucket"]
  conditions: Condition[];   // EVERY condition must hold; any failure is a violation
  message: string;
}

interface Condition {
  path: string;              // dot path relative to the resource root ("" for forbid_pattern)
  op: CondOp;
  value?: unknown;
}

Ten operators: exists, absent, eq, neq, in, not_in, gte, lte, regex, forbid_pattern. Each has a Rego rendering in compile.ts and a TypeScript implementation in engine.ts — a matched pair.

The path is relative to a provider-specific base: change.after for Terraform, the manifest root for Kubernetes, Properties for CloudFormation.

RuntimeTarget — an agent rule#

interface RuntimeTarget {
  check: "tool_scope" | "pii_egress" | "classification_egress"
       | "step_budget" | "tool_denylist";
  blockedClassifications?: string[];  // classification_egress
  maxSteps?: number;                  // step_budget (default 20)
  deniedTools?: string[];             // tool_denylist
  message: string;
}

PolicyBundle — the versioned artifact#

interface PolicyBundle {
  id: string; version: number; title: string;
  createdAt: string; createdBy: string;
  controlIds: string[];            // exactly what was approved at compile time
  staticRego: string;              // package grc.static
  runtimeRego: string;             // package grc.runtime
  tests: PolicyTest[];             // 6 IaC fixtures + 9 runtime scenarios
  testResults: TestResult[];       // { expect, builtin, opa?, passed }
  semanticConsistency: number | null;  // % agreement; null when OPA was unavailable
}

The Rego is stored on the bundle, not regenerated — so evidence shows the exact bytes that were enforced.

ChangeRequest — the approval gate#

interface ChangeRequest {
  id: string; title: string; bundleId: string;
  createdBy: string; createdAt: string;
  status: "open" | "published" | "rejected";
  approvals: {
    security?: { user: string; at: string };
    aiops?:    { user: string; at: string };
  };
  publishedAt?: string;
}

AgentDef / ToolDef — the runtime governance metadata#

interface AgentDef  { id; name; role; description;
                      scopes: string[]; allowedTools: string[]; source?: string }

interface ToolDef   { name; description;
                      external: boolean;                        // crosses the trust boundary
                      dataAccess: "public" | "internal" | "pii";
                      source?: string }                          // "mcp:https://…"

external and dataAccess drive every egress check. A tool missing from the registry is treated as external: true at authorization time.

Waiver#

interface Waiver {
  id; controlId; reason; createdBy; createdAt; expiresAt;
  status: "active" | "expired" | "revoked";
  revokedBy?; revokedAt?;
  scope?: { agentId?: string; toolName?: string; resource?: string };
}

getActiveWaivers() flips past-due rows to expired as a side effect of every read — expiry needs no scheduler. A waiver with no scope exempts the control everywhere.

Decision / ScanRecord — the enforcement records#

Both capture the verdict, the reasons (control, message, severity), and — importantly — which engine decided ("opa" | "builtin").

AuditEntry — the hash chain#

interface AuditEntry {
  id; at; user; action; detail;
  hash?: string;   // SHA-256(id + at + user + action + detail + prevHash)
}

The genesis previous-hash is 64 zeros. verifyAuditChain() walks the chain and reports the first index where a recomputed hash disagrees.

State — everything, in memory#

interface State {
  documents; controls; bundles; activeBundleId;
  prs; agents; tools; decisions; scans; users; audit; waivers; seq;
}

state() materialises this from every table; handlers mutate it; save() writes it all back. Simple, and the reason a single writer is required.

The SQLite schema#

better-sqlite3, WAL journal mode, foreign_keys = ON, schema auto-created on first connection at <cwd>/<DATA_DIR>/grcstudio.db.

12 tables:

Notable columns#

controls — staticTargets and runtimeTargets are JSON text. New target shapes need no migration, and get no column-level validation; the guard is the Zod schema plus LLM output sanitisation at the boundary.

bundles — staticRego and runtimeRego are the generated source, stored verbatim. semanticConsistency is REAL and nullable — null is meaningful (OPA was unavailable), not missing data.

users — email is UNIQUE; passwordHash is nullable, and the three seeded users are created without one. See G5 for why that matters.

tools — the primary key is name, so tool names are globally unique. Renaming a tool breaks any agent's allowedTools that references it; there is no cascade.

Persistence pattern#

save() rewrites the whole state:

TableStrategy
documents, controls, bundles, prs, agents, tools, waiversUpsert (INSERT … ON CONFLICT DO UPDATE)
usersUpsert that preserves passwordHash and email — a reseed cannot wipe credentials
audit, decisions, scansDelete-and-reinsert

That last row is worth internalising: rows outside the in-memory window are deleted. state() loads only the most recent 300 audit entries, 200 decisions, and 100 scans; the next save() then removes everything else from the table. History is bounded in storage, not just in the working set — raise AUDIT_MAX_ENTRIES and friends before you accumulate anything you need to keep, or export regularly.

Settings — deliberately outside the database#

data/settings.json, mode 600, holding the Anthropic key, the model choice, and the engine preference. Optionally AES-256-GCM encrypted when SETTINGS_KEY is set (format enc:<iv>:<tag>:<ciphertext>). Kept separate so POST /api/reset cannot destroy configuration.

Identifiers, timestamps, and conventions#

Migration#

npm run migrate (src/migrate.ts) imports a legacy data/state.json into SQLite. There is no versioned migration framework — initSchema() is CREATE TABLE IF NOT EXISTS, so schema changes on an existing database need a hand-written ALTER TABLE.
